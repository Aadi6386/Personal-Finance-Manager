# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-29

### Added

- Flask-based Personal Finance Manager
- SQLite database integration
- Income and expense tracking
- Transaction categories
- Transaction descriptions and dates
- Transaction search and filtering
- Edit and delete transaction functionality
- Financial dashboard
- Total income calculation
- Total expense calculation
- Current balance calculation
- Transaction count
- Category-based budgets
- Budget spending tracking
- Remaining budget calculation
- Budget usage percentage
- Savings goals
- Monthly financial analytics
- Monthly income and expense analysis
- Monthly savings calculation
- Savings rate calculation
- Top spending category detection
- Category-wise spending analysis
- Daily spending analysis
- Responsive HTML/CSS interface
- JavaScript frontend functionality
- SQLite database persistence

### Technical

- Python used as the primary programming language
- Flask used for backend routing
- SQLite used for database storage
- Jinja2 used for server-side HTML templates
- CSS used for responsive styling
- JavaScript used for frontend interactions
